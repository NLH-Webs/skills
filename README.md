## LUAT CUA KHO NAY

**Day la kho CONG KHAI. Kho nay chua PHUONG PHAP, khong chua DU LIEU.**

Khong dua vao day:
- Ban do he thong noi bo, danh sach lo hong bao mat, ten may chu, duong dan API
- So lieu tai chinh, doanh thu, luong, so hoc vien
- Ten nguoi, so dien thoai, email, bat ky du lieu ca nhan nao
- Gu san pham rieng va cac chot nghiep vu cua NhiLe

Mot skill o day phai dung duoc cho bat ky san pham nao, ke ca cua khach ngoai. Neu phai biet mot con so noi bo moi dung duoc thi no chua phai skill - no la tai lieu noi bo de nham cho.

## Cach them mot skill

1. Tao thu muc <ten-skill>/ (chu thuong, gach ngang).
2. SKILL.md mo dau bang khoi frontmatter: name va description. Description phai noi ro skill lam gi VA dung khi nao - chinh cau nay quyet dinh skill co duoc goi dung luc khong.
3. Tai lieu dai de trong references/, goi tu SKILL.md khi can.
4. Truoc khi day: doc lai mot luot, tim ten nguoi, so lieu, duong dan noi bo. Co thi bo hoac viet chung lai.
